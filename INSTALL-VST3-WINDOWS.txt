QUADBEAT FX VST3 - WINDOWS / FL STUDIO INSTALLATION

1. Close FL Studio and extract the complete QuadBeatFX-Windows-x64 ZIP.
2. Double-click Install-QuadBeatFX-VST3.cmd. Administrator access is not required.
3. Confirm the installer reports success. It installs the complete bundle for your account at:
   %LOCALAPPDATA%\Programs\Common\VST3\QuadBeat FX.vst3
4. Open FL Studio and select Options > Manage plugins.
5. Enable Verify plugins, Rescan previously verified plugins, and Rescan plugins with errors.
6. Select Find installed plugins and wait for verification to finish.
7. Load QuadBeat FX in a Mixer effect slot. It is an effect, not a Channel Rack instrument.

The required module is:
%LOCALAPPDATA%\Programs\Common\VST3\QuadBeat FX.vst3\Contents\x86_64-win\QuadBeat FX.vst3

For a system-wide installation, open PowerShell as administrator in the extracted package and run:
powershell -ExecutionPolicy Bypass -File .\Install-QuadBeatFX-VST3.ps1 -AllUsers

Do not copy only the inner module, rename it to .dll, put it in FL Studio's installation folder, or
use a custom VST2 search folder. FL Studio only scans VST3 plug-ins from standard system locations.
This self-contained build is 64-bit and requires 64-bit FL Studio on Windows 10 or 11.
