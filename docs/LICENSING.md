# Licensing and distribution review

Original project code is an all-rights-reserved placeholder. That choice is not automatically
compatible with every JUCE licensing path. Obtain an appropriate JUCE license or deliberately
adopt a compatible open-source license before distribution. Review the JUCE 8.0.13 terms from the
authoritative source rather than relying only on this summary.

ASIO-enabled Windows distribution may carry separate Steinberg SDK/trademark obligations. No
proprietary SDK or private license is stored here. A qualified reviewer must assess the intended
distribution model, JUCE terms, ASIO terms, and notices.

The reference image is documentation-only, unmodified, excluded from packages, and not evidence of
permission to reproduce a product design. QuadBeat FX uses original branding and does not include
third-party manufacturer identity. This repository is not yet represented as cleared for
commercial distribution.
